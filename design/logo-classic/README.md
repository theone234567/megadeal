# Classic browser-tab and home-screen icons

The cartoon-elephant icons the site used before the minimal logo:
`favicon.ico`, `icon.png` and `apple-icon.png`, exactly as they were in `app/`.

To restore them, copy all three back over the files of the same name in `app/`.
The headers, share images and emailed logo switch back separately, with
`LOGO_STYLE` in `lib/brand.ts`.
